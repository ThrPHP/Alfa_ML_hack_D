# Решения и причины

| решение | почему |
|---|---|
| Архитектура «гибрид»: LLM выдаёт гипотезы строгим JSON, ml_core их исполняет; код пишет только для признаков | Qwen-27B ненадёжна как свободный кодогенератор, токены дорогие (600 ₽/день на команду), а честную валидацию легко сломать. FE — главный источник прироста, поэтому его оставили через песочницу |
| Модель не скачиваем и не дообучаем | запрещено правилами, нет GPU, не нужно: LLM только планирует |
| Метрика из текста task.md важнее ответа LLM; LLM-метрика принимается, только если есть в ml_core и подходит к типу задачи | галлюцинация не должна менять, что оптимизирует весь прогон |
| `time_split` только если все значения колонки в test позже всех в train, 1 фолд на последнем периоде | ловит `Year_Factor`, не ловит ложные `swin/dwin`; при n_splits>1 в ml_core в train попадают более поздние периоды |
| 3 фолда при >30k строк, иначе 5 | бюджет времени: CatBoost-мультикласс ~100 с/фолд |
| Код признаков от LLM — только через песочницу (allowlist импортов, отдельный процесс на реальных данных, детерминизм, те же строки, без таргета); `py:`-шаги — только принятые песочницей | защита от ошибок и галлюцинаций; не даёт LLM запустить произвольный файл |
| `SubprocessExecutor` по умолчанию, лимит 30 мин на эксперимент | таймаут ml_core мягкий (между фолдами); зависший fit не должен съесть 3 часа |
| Сначала fallback-сабмит, refit после seeds, чекпоинт раз в 30 мин | к kill на 3-м часу всегда есть хороший файл |
| Без LLM — playbook общих идей, потом local search по 1–2 гиперпараметрам | агент полезен и без ключа / после исчерпания лимита; не простаивает |
| Seeds для большого мультикласса дешевле (LightGBM 300 деревьев, lr 0.1) | дерево на каждый класс в каждом раунде → в 10 раз дороже |
| Гиперпараметры: потоки/seed/verbosity/GPU задаёт агент; итерации ≤4000, глубина и lr ограничены | LLM не может съесть бюджет одним конфигом |
| В playbook XGBoost с `max_cat_threshold=32` | без этого переобучение на категориальных (RMSE 160–236) |
| Промпты на английском, task.md как есть | меньше токенов |
| Ключ — сетевым секретом окружения, в `OPENAI_API_KEY` заглушка | ключ не попадает в контейнер и репо |
