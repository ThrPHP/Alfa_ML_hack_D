1. **Не звать LLM, когда на эксперимент не хватит времени**: в конце прогона мультикласса 3 раунда подряд все
   гипотезы пропущены «not enough time» — ~1 ₽ впустую и ложный счёт «раундов без рекорда». Перед раундом
   сравнивать остаток с длительностью лучшего эксперимента.
2. **Seed CatBoost для большого мультикласса** — дешевле (меньше итераций) или после первых LLM-раундов: сейчас
   ~8 мин на 4 CPU и он слабее LightGBM на обеих задачах.
3. **Терпение LLM-фазы** (`AGENT_PATIENCE=4`): на регрессии LLM отключилась на 6-й минуте. Для 3 ч — вернуться к
   LLM после playbook/local search (новая история → новые идеи) или считать терпение по времени, а не по раундам.
4. **Плоский ZIP** (если пользователь возьмёт на себя, иначе передать инфраструктуре): скрипт сборки, который
   кладёт модули `ml_core/*.py`, `agent/*.py` в корень с переименованием и переписывает импорты; `solution.py`;
   проверка: распаковать в чистую папку с данными задачи и запустить `python3 solution.py task.md`.
   Учесть: `SubprocessExecutor` запускает `python -m agent._worker` (cwd = `experiments/_worker`), песочница —
   `_feature_sandbox_runner.py` по пути рядом с модулем.
5. Устойчивость однофолдовой валидации регрессии: несколько seed / проверка лучшего конфига на втором периоде,
   чтобы local search не подгонялся под один фолд.
6. Улучшения качества: ансамбль top-2 моделей разных семейств; метрики на вероятностях (вместе с Тимой).
