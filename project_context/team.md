## Что передать
**Тиме:**
- коммит `a680722` — в ml_core реализованы `feature_steps` (применяются внутри CV-фолдов), просьба посмотреть;
- XGBoost по умолчанию переобучается на категориальных (`facility_type`, 57 категорий): RMSE 160 против 59
  с `max_cat_threshold=32` — стоит поменять дефолт в `model_registry`;
- ml_core не умеет метрики на вероятностях (ROC-AUC, logloss) — риск для private-задач;
- LightGBM на обеих задачах сильнее CatBoost; на регрессии важна регуляризация (сдвиг между годами);
- агент теперь вызывает `model_registry.build_model(...)` без обучения, чтобы отсеять параметры, которых модель
  не принимает: если меняешь сигнатуру `build_model` — скажи нам;
- CatBoost-мультикласс ~160 с/фолд на 4 CPU — возможно, стоит дешевле дефолт для больших мультиклассов.

**Инфраструктурщику:**
- `docs/AGENT_CONTRACT.md`: вход `agent.research.run_research(task_md, deadline_ts)`, пример `solution.py`;
- жёсткие таймауты уже есть в агенте (`SubprocessExecutor`), можно заменить своим Executor;
- **ZIP должен быть плоским** (см. case.md) — нужна сборка, раскладывающая пакеты в корневые модули;
  `python -m agent._worker` и путь к `_feature_sandbox_runner.py` при этом нужно переписать;
- в `solution.py` закладывать ~10 мин запаса до kill (`deadline_ts = старт + 3 ч − 10 мин`);
- если сами зовёте LLM: прокси режет непотоковые запросы на ~30 с → `stream=True`; расход — `GET /key/info`;
- LLM стоит ~11–20 ₽ на задачу за 3 ч; результаты с LLM: RMSE 41.86 (без — 42.97), Macro F1 0.6165 (без — 0.580).
