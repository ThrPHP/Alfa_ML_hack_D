## Что считаем результатом части «LLM-агент»
**Артефакт — релиз `agent-v1`**: коммит в ветке `claude/fervent-lamport-31kwal` (git-тег `agent-v1`), в котором есть:
1. Пакет `agent/` с замороженным интерфейсом `agent.research.run_research(task_md, deadline_ts)`
   (контракт — `docs/AGENT_CONTRACT.md`): сам пишет `submission.csv` рядом с `task.md`, никогда не падает.
2. Отчёт о приёмке `project_context/acceptance.md`: таблица прогонов «без LLM / с LLM» на обеих public-задачах,
   расход ₽ на задачу, ссылки на `report.md`.
3. Документация для следующего участника: `AGENTS.md`, `project_context/repo_map.md`, презентация
   `docs/presentation/agent_deck.html`.

## Критерии приёмки `agent-v1`
| # | критерий | как проверяем | сейчас |
|---|---|---|---|
| 1 | все тесты зелёные | `pytest tests/` | ✅ 55/55 |
| 2 | с LLM не хуже, чем без LLM, на обеих задачах (30-мин прогон) | `run_agent_local.py --budget-s 1800` | регрессия ✅ (41.86 против 42.97), мультикласс — идёт прогон |
| 3 | сабмит есть при любом сбое: нет ключа, `Budget has been exceeded`, LLM отвечает мусором, kill по времени | тесты `test_agent_llm.py`, `test_agent_research.py` | ✅ |
| 4 | расход LLM ≤ 25 ₽ на задачу за 3 ч | `report.json → llm_usage.cost` на одном длинном прогоне | оценка 15–20 ₽, длинного прогона не было |
| 5 | укладывается в 3 ч с запасом и успевает финальный refit | один прогон с `--budget-s 10800` (можно ночью, без LLM — бесплатно) | не проверено |
| 6 | работает из плоской раскладки (как в ZIP) | прогон из собранного инфраструктурой ZIP | ждём инфраструктуру |

Пункт 6 — общий с инфраструктурой: мы даём список модулей и особенности (`python -m agent._worker`,
`_feature_sandbox_runner.py` рядом с модулем), сборку делают они.
