# Кейс «Альфа Хак AutoML»

Источник: `Base/Альфа Хак_AutoML.pdf` + инструкция организаторов по ключам и загрузке (Google Doc «AutoML_Инструкция по ключам»).

## Задача
AI-агент, который сам решает ML-задачу на табличных данных: читает `task.md`, изучает данные, определяет тип
задачи и метрику, строит валидацию, выдвигает и проверяет гипотезы (цикл AutoResearch: гипотеза → эксперимент →
оценка → следующая итерация), выдаёт `submission.csv`. Один код для любых задач, без ручной настройки под датасет.

## Данные
В каждой задаче: `train.csv`, `test.csv`, `data_dictionary.csv` (feature, role, dtype, unit, description_ru),
`sample_submission.csv`. Пути в `task.md` указаны относительно него (на платформе вида
`regression/participants/train.csv`; в нашем репо файлы лежат рядом с `task.md`).

| | public 1 | public 2 |
|---|---|---|
| задача | регрессия: `site_eui` (энергопотребление зданий) | мультикласс: `attack_cat` (10 типов атак, UNSW-NB15) |
| train / test | 53 308 / 22 449 | 87 670 / 41 166 |
| метрика | RMSE ↓ | Macro F1 ↑ (accuracy, weighted F1 — справочно) |
| особенность | `Year_Factor`: train 1–5, test только 6 | сильный дисбаланс (Worms — 65 строк), треть строк — дубликаты |

Private: две новые задачи, их содержание и метрики не раскрываются («метрики могут различаться»).
Платформа берёт последнюю версию с лучшим public score и перезапускает её на private.

## Score
- Регрессия: `S = 100 · max(0, 1 − RMSE / B_rmse)`; классификация: `S = 100 · max(0, (F1 − B_f1) / (1 − B_f1))`,
  где B — результат бейзлайна организаторов. Уровень бейзлайна или хуже = 0.
- Public = среднее двух задач; private = среднее двух private-задач.

## Ограничения
- Python 3.12, только библиотеки из `Base/requirements.txt`, ставить пакеты из кода нельзя.
- Docker: 8 CPU, 32 GB RAM, **3 часа на задачу** (потом kill, оценивается уже записанный файл).
- Интернета нет; доступен только прокси к LLM. Модель — Qwen (`qwen/qwen3.8-27b`), другие модели и
  предобученные веса запрещены. Модель **не дообучаем**, она только планирует.
- LLM-лимит: **600 ₽/день на ключ команды**, общий для всех; при превышении ошибка
  `Budget has been exceeded`, сброс в 3:00 МСК. Расход виден в `GET https://changellenge.up.railway.app/key/info`
  (`spend`, ₽); особенности прокси (30 с без потока, поле `reasoning`) — в `insights.md`.
- 3 сабмита в день на команду (сброс в 00:00 МСК).

## Инструкция организаторов: подключение и сабмит
- Подключение: OpenAI-совместимый API, base URL `https://changellenge.up.railway.app/v1`,
  модель `qwen/qwen3.8-27b`. В решении адрес и ключ брать **только** из `OPENAI_BASE_URL` / `OPENAI_API_KEY`
  (платформа подставит); имя модели — из `OPENAI_MODEL` или любое (прокси подставит своё).
- Запуск на платформе: `python3 solution.py task.md`, рабочая папка = папка `task.md`,
  `submission.csv` сохранять туда же; промежуточные файлы — в папке задачи или `/tmp`.
- **ZIP: все файлы в корне архива, без папок.** Копируются только корневые `.py` и `requirements.txt`;
  вложенные папки и прочие файлы не копируются → модуль из подпапки будет недоступен → можно получить 0.
  Размер ZIP до 100 МБ. `.whl` и сторонние пакеты нельзя.
- Ошибки проверки: «Превышено время обработки решения» (учитывается и время LLM), «отсутствует файл …»
  (нет `submission.csv` рядом с `task.md`), «Ошибка формата данных».
