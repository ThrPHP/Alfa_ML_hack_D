Главное решение03

Гибрид: LLM пишет план в строгом JSON, исполняет его ml_core

Что делает LLM

  • понимает задачу: метрика, колонки времени и групп, что выбросить
  • предлагает до 3 гипотез за раунд: модель, параметры, предобработка, признаки
  • пишет код признаков make_features(df)
  • читает историю экспериментов и решает, что пробовать дальше

Что делает код

  • одна фиксированная валидация для всех гипотез
  • проверяет и ограничивает параметры, отбрасывает повторы
  • прогоняет код признаков в песочнице
  • следит за временем, обучает финальную модель, пишет сабмит

Почему не «LLM пишет весь пайплайн»

  • 27B-модель ненадёжна как свободный кодогенератор
  • честную валидацию легко сломать утечкой
  • токены платные и общие на команду
  • без LLM агент тоже работает: playbook и local search

Один прогон05

Как агент тратит 3 часа

старт
seeds
раунды LLM
playbook · local search

Пропорции примерные: LLM-фаза длится, пока даёт новые рекорды (4 раунда без рекорда — переход дальше).

Старт, ~20 сПрофиль данных и сразу fallback-сабмит. Затем один вызов LLM: метрика, время, группы.
SeedsLightGBM и CatBoost по умолчанию, refit лучшего, настоящий сабмит уже на 1-й минуте.
Раунды LLMДо 3 гипотез за раунд, каждая — изменение лучшего конфига. История и ошибки уходят в следующий промпт.
Playbook и local searchОбщие проверенные идеи, затем точечный подбор 1–2 гиперпараметров. Работают и без ключа.
RefitЧекпоинт сабмита раз в 30 мин и финальный. Резерв на refit агент калибрует по факту.

Надёжность07

Что не даёт агенту сломать результат

Сабмит всегда есть

Fallback на 2-й секунде, refit после seeds, чекпоинты раз в 30 мин. Запись атомарная.

Метрику не переспорить

Метрика из текста task.md важнее ответа LLM. Ответ LLM принимается, только если такая метрика есть в ml_core и подходит к типу задачи.

Честная валидация

time_split включается, только если весь test строго позже train. Признаки обучаются внутри фолдов.

Жёсткие таймауты

Каждый эксперимент — отдельный процесс. Зависший fit убивается и не съедает 3 часа.

LLM — помощник, а не опора

Нет ключа, сбои, мусорные ответы → агент продолжает на playbook. Budget has been exceeded → LLM отключается сразу, без повторов.

Код от LLM — в песочнице

Только разрешённые импорты, детерминизм, те же строки и порядок, без таргета, не больше N новых колонок.

Стоимость10

Сколько стоит LLM

≈0.4 ₽

один раунд гипотез (~4 тыс. токенов на вход, ~1.5 тыс. на выход, ~25 с)

15–20 ₽

одна задача за 3 ч (до 40 вызовов). Худший случай — ~70 ₽, если каждый ответ упрётся в лимит

30–40 ₽

один сабмит (2 задачи). 3 сабмита в день — примерно 100–120 ₽ из 600

Цена определяется выходом: ≈0.27 ₽ за 1000 токенов ответа вместе с рассуждением, вход в разы дешевле. Поэтому длину рассуждения ограничиваем, а промпт держим компактным, на английском.

Дальше12

Следующие шаги

Не звать LLM впустую

В конце прогона LLM трижды предлагала гипотезы, на которые уже не хватало времени. Перед раундом сверять остаток с длительностью эксперимента.

LLM все 3 часа

Сейчас после 4 раундов без рекорда LLM уходит насовсем, на регрессии это случилось на 6-й минуте. Нужно возвращаться к ней после playbook и local search.

Дешевле стартовый CatBoost

На мультиклассе он занимает 8 минут и проигрывает LightGBM на обеих задачах.

Устойчивая валидация

Несколько seed или второй период для регрессии, чтобы перебор параметров не подгонялся под один фолд.

Качество

Ансамбль двух лучших моделей разных семейств. Метрики на вероятностях (ROC-AUC, logloss) — вместе с Тимой.
